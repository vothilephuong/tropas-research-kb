# TROPAS Research KB

Knowledge Base cho luận án dự báo khí tượng thiên văn nhiệt đới (TROPAS).  
So sánh song song output từ 4 AI tools — Claude, ChatGPT, Gemini, Perplexity — theo từng topic nghiên cứu.

## Quick Start

```bash
# Prerequisites: Node.js >= 20
nvm use            # uses .nvmrc
npm install
npm run kb:prepare # validate + generate manifest
npm run dev        # http://localhost:5173/tropas-research-kb/
```

## Architecture

```
Static site — React + TypeScript + Tailwind v4
No backend · No database · Deploy to GitHub Pages
```

### Folder Structure

```
public/data/
├── manifest.json          ← auto-generated by kb:prepare
├── citations.json         ← hand-curated citation database
└── topics/
    └── {topic-id}/
        ├── meta.json      ← topic metadata
        ├── claude.md
        ├── chatgpt.md
        ├── gemini.md
        ├── perplexity.md
        └── assets/        ← optional images/PDFs
```

### Key Components

| Component | Purpose |
|-----------|---------|
| `ComparatorView` | 4 AI columns side-by-side |
| `ReaderPage` | Full-page single AI reader |
| `CitationsPage` | Citation list with filter/sort/expand |
| `TopicTree` | Sidebar navigation from manifest |
| `MarkdownViewer` | react-markdown + GFM + highlight |

## Adding a New Topic

1. Create folder: `public/data/topics/{topic-id}/`
2. Add 4 AI files: `claude.md`, `chatgpt.md`, `gemini.md`, `perplexity.md`
3. Add `meta.json`:
   ```json
   {
     "id": "topic-id",
     "title": "Topic Title",
     "description": "Short description",
     "tags": ["tag1", "tag2"],
     "status": "complete",
     "created": "2026-01-01",
     "files": {
       "claude": "claude.md",
       "chatgpt": "chatgpt.md",
       "gemini": "gemini.md",
       "perplexity": "perplexity.md"
     }
   }
   ```
4. Run `npm run kb:prepare`
5. App tự nhận — không cần sửa code

## Content Pipeline

```bash
npm run kb:prepare
# Step 1: validate-content.mjs — checks meta.json, file refs, citations
# Step 2: generate-manifest.mjs — builds manifest.json from topics
```
